## 目标
首页历史月份数字改为从处方表实时聚合，彻底摆脱 `myDbs_userconfig` 的每月手工加列和快照任务。

## 改动
1. **server/sqlMap.js**：新增 `getMonthlyTotals: 'SELECT DATE_FORMAT(date, "%Y-%m") AS ym, SUM(total) AS total, SUM(totalprofit) AS profit FROM ?? GROUP BY ym ORDER BY ym'`。
2. **server/api.js**：新增 `getMonthlyTotals` 处理器（dbPrefix 经 clinicTables 校验，返回 [{ym,total,profit}]）；**server/router.js** 注册 `GET /getMonthlyTotals`。
3. **src/views/Dashboard.vue**：
   - mounted 并行请求近 30 天明细（当天/当月卡片、每日图仍用它）+ 新月度接口；
   - 重写 `setMonthChart`：每月图 12 个月（当月实时+历史聚合）、全年收入=当年各月之和（含当月实时）、总收入=全部月份之和；不再读写 userconfig 的月份列。
4. **src/store/modules/userconfig/actions.js**：删除 `ensureLastMonthSnapshot`（loadUserSetting 保留，继续管显示开关等配置）。
5. 旧接口 `getChartInfoFromOrder`、`saveMonthTotalToUserSetting` 与数据库历史月份列保留不动（前端不再调用，后续想清理另说）。

## 验证
- `npm run lint -- --no-fix` + `npm run build`；`node --check server/api.js server/router.js server/sqlMap.js`。
- 后端在跑则 curl `/api/getMonthlyTotals?dbPrefix=qcui_` 看月度数组。
